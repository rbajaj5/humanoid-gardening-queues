# Synthetic Watering: Queue-Aware Coordination

42-second narrated/captioned schematic MP4 at 1920x1080, 25 fps.
New gardening results, not repackaged laundry data.

Experiment: 256 matched seeds, six communication conditions, three policies,
4,608 episodes. The movie uses preselected seed 45100 for lost completion
receipts and permanent observation loss. All metrics come from saved traces.

Stable command IDs prevent duplicate dose execution under the model assumptions.
Fresh observed delivery permits progress without receipts. But permanently
missing observations stop the queue-aware controller even when reliable
completion receipts would allow safe progress. The negative case is included.

This is CPU task-level accounting and communication, not an articulated humanoid,
fluid/soil simulation, GPU experiment, trained policy or hardware validation.
The original request's mass-bearing GPU humanoid demonstration is in the separate
humanoid-laundry-queues repository. Gardening physics remains future work.

Source, configuration, all episode outcomes, 18 complete replays, test reports,
aggregate tables and movie-to-trace indices are in this repository. No API keys,
private class papers or externally licensed robot assets are bundled.
